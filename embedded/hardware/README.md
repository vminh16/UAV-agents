# Phần cứng

Danh mục (BOM), so sánh máy tính đồng hành, sơ đồ đấu nối, ngân sách thời gian và lộ trình nâng cấp: [`docs/03-architecture/60-hardware.md`](../../docs/03-architecture/60-hardware.md).

Thư mục này chứa: ảnh lắp ráp, bảng cân khối lượng thực tế, sơ đồ dây chi tiết theo bản lắp thật, kết quả đo rung / công suất.
